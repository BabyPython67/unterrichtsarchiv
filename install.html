Lesezeichen anlegen

Zum Viewer

Einmalig einrichten, danach reicht ein Tipp im Schulmanager.

Das Lesezeichen holt deine Unterrichtsinhalte und Hausaufgaben aus dem Schulmanager-Tab, in dem du schon eingeloggt bist, und schickt sie an den Viewer. Es fragt nie nach einem Passwort und speichert nichts auf einem Server.

Am Computer

Diesen Knopf mit der Maus in die Lesezeichenleiste ziehen (nicht anklicken):

Unterrichtsarchiv holen

Lesezeichenleiste einblenden: Chrome/Edge Strg+Umschalt+B, Firefox über „Ansicht → Symbolleisten". Alternativ: irgendeine Seite als Lesezeichen speichern, dann das Lesezeichen bearbeiten und als Adresse den Text aus dem Feld unten einfügen.

Kennung dieses Lesezeichens: Build …. Dieselbe Kennung zeigt die Statusbox im Schulmanager. Weicht sie ab, ist dein Lesezeichen veraltet: altes löschen, neu ziehen.

iPhone und iPad (Safari)

  1. Unten auf „Kopieren" tippen, damit die Lesezeichen-Adresse in der Zwischenablage liegt.
  2. Diese Seite über „Teilen" → „Lesezeichen hinzufügen" sichern. Name z. B. Unterrichtsarchiv holen.
  3. Lesezeichen-Übersicht öffnen → „Bearbeiten" → das neue Lesezeichen antippen → im Feld „Adresse" alles löschen und den kopierten Text einfügen → „Fertig".
  4. Benutzen: Im Schulmanager eingeloggt in die Adressleiste tippen, „Unterrichtsarchiv" eingeben und das Lesezeichen aus den Vorschlägen wählen.

Android (Chrome)

  1. „Kopieren" tippen.
  2. Diese Seite über das Menü ☆ als Lesezeichen speichern, dann Lesezeichen → ⋮ → „Bearbeiten" → Adresse durch den kopierten Text ersetzen.
  3. Benutzen: Im Schulmanager eingeloggt den Lesezeichennamen in die Adressleiste tippen und das Lesezeichen wählen.

Was beim Antippen passiert

  1. Der Viewer öffnet sich in einem neuen Tab.
  2. Das Lesezeichen holt einmal Inhalte und Hausaufgaben (kein Dauerabruf).
  3. Der Viewer übernimmt sie: neue Einträge kommen dazu, geänderte werden aktualisiert, nichts wird gelöscht.
  4. Wird das neue Fenster blockiert, lädt das Lesezeichen stattdessen eine Datei herunter, die du im Viewer unter Einstellungen → Daten → „Importieren" einliest.

Im Schulmanager-Tab erscheint oben rechts eine kleine Statusbox. Falls etwas schiefgeht, steht dort der Grund; mit „Meldung kopieren" lässt er sich weitergeben.
